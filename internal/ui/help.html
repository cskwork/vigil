도움말

화면에 나오는 말이 무슨 뜻인지, 무엇을 하면 되는지 정리했습니다. 메뉴의 목차에서 필요한 표로 바로 갈 수 있습니다.

vigil이 하는 일

사람이 시키지 않아도 이 네 단계가 계속 돕니다.

  1. 1. 신호 감지새 커밋, Jira 이슈, 운영 로그에서 확인할 거리를 찾습니다.
  2. 2. AI가 재현하고 검사 작성AI가 브라우저로 직접 눌러 증상을 재현하고 검사 절차를 만듭니다.
  3. 3. 사람이 확인하고 승인사람이 증거를 보고 승인해야 정식 검사가 됩니다. 승인 전에는 아무것도 자동으로 돌지 않습니다.
  4. 4. 매일 자동 실행승인된 검사는 매일 정해진 시각과 배포 직후에 실행되고, 실패하면 할 일 화면에 올라옵니다.
