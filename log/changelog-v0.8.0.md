# v0.8.0 — 관리 콘솔에서 승인된 검사도 바로 실행합니다

## 고친 문제

- `vigil admin`은 정기 스케줄러를 시작하지 않아 승인된 정식 검사도 **실행** 버튼으로만 돕니다. 그런데 검사 목록은 승인 대기와 확인 필요 상태에만 동작 버튼을 그려, 정식 검사에는 실행 버튼이 없었습니다. 상세 화면은 "실행 버튼에서 사이트를 선택해 검증할 수 있습니다"라고 안내해 화면과 안내가 어긋났습니다.
- 이제 관리 콘솔에서는 **쓰지 않음**으로 분류된 검사를 제외한 모든 검사에 실행 버튼이 있습니다. 사이트와 브라우저를 고르는 기존 실행 메뉴를 그대로 씁니다.
- 승인과 반려 버튼은 계속 승인 대기와 확인 필요 검사에만 표시합니다.

## 호환성과 범위

화면 표시만 바꿨습니다. 실행 API, 데이터베이스, 검사 상태와 승인 조건은 그대로입니다. `loop --ui` 화면은 스케줄러가 정식 검사를 실행하므로 이전과 같이 동작합니다.

## 검증

- 전체 Go 테스트와 `go vet ./...`.
- 실제 Chromium에서 관리 콘솔을 조작했습니다. 정식 검사 목록에 실행 버튼만 나타나고, 목록에서 실행한 검사가 끝까지 통과했습니다. 승인 대기 검사 6개는 실행·승인·반려 버튼을 모두 유지했습니다.
- `TestAgentEnvPrefersTheOperatorCredential`는 셸에 `Z_AI_API_KEY`가 설정된 환경에서 v0.7.0부터 실패합니다. 이번 변경과 무관하며, 해당 변수를 비운 환경에서 전체 테스트가 통과했습니다.
