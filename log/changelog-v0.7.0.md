# v0.7.0 — 화면 첨부로 요청하고, 사용할 AI를 고릅니다

## 변경 사항

- 검증 요청에 화면 이미지(PNG, JPEG, GIF, WebP)와 녹화 영상(MP4, MOV, WebM)을 최대 8개, 합계 128MB까지 첨부할 수 있습니다. 설명을 비워 두고 첨부만 올려도 접수됩니다.
- 에이전트가 첨부에서 화면, 조작한 요소, 입력한 값과 그 결과를 읽어 가장 가능성이 높은 시나리오 하나를 고릅니다. 고른 근거와 함께 검토하다 버린 해석도 결과의 근거란에 남깁니다. 화면을 알아볼 수 없으면 지어내지 않고 사람 확인이 필요한 상태로 돌려보냅니다.
- 녹화 영상은 `ffmpeg`로 시간 순서의 화면 여러 장으로 나누어 전달합니다. 영상 파일 자체는 모델에 보내지 않습니다. `ffmpeg`가 없으면 그 사실을 알리고 캡처 이미지를 함께 올리도록 안내합니다.
- 새 **LLM 설정** 화면에서 검증을 수행할 AI를 고릅니다. 관리자 기본 설정, 내 API 키(Anthropic, GLM Coding Plan, OpenAI, OpenAI 호환 엔드포인트), 내 코딩 에이전트(Claude Code, Codex, pi) 중에서 선택합니다.
- API 키는 소유자만 읽을 수 있는 파일에 저장하고 화면에는 끝 네 자리만 표시합니다. 저장하기 전에 제공자의 모델 목록으로 연결을 확인하므로 잘못된 키나 모델 이름은 저장되지 않습니다.
- OpenAI 호환 엔드포인트는 vigil이 생성한 pi 확장으로 등록합니다. 사용자의 `~/.pi/agent/models.json`을 수정하지 않습니다.
- 새 명령 `vigil mcp-browser`가 브라우저 도구 하나를 MCP로 제공합니다. 내 코딩 에이전트를 선택해도 같은 시스템 프롬프트와 같은 결과 형식을 사용합니다.
- 첨부 파일은 증거 폴더의 `requests/<시각>/`에 보관하며 실패 증거와 같은 기간(`evidence.retain_fail_days`)이 지나면 정리합니다.

## 호환성과 범위

기존 설정, 데이터베이스, 검사 상태와 승인 조건을 그대로 유지합니다. LLM 설정을 바꾸지 않으면 기존 `agent.models` 설정으로 동작합니다. `agent.provider`에 `claude` 또는 `codex`를 지정할 수 있으며 기본값은 `pi`입니다.

내 코딩 에이전트 모드에서도 대상 서비스 코드는 수정하지 않습니다. 다만 격리 수준은 다릅니다. Claude Code는 `--restricted`와 `--strict-mcp-config`로 브라우저·읽기 도구만 사용하며 셸이 없습니다. Codex는 `read-only` 샌드박스에서 실행하고 vigil 브라우저 도구만 사전 승인하지만, 자체 읽기 전용 셸은 그대로 있습니다.

## 고친 문제

- Codex의 브라우저 도구 호출이 승인 정책에 막혀 실행되지 않던 문제를 고쳤습니다.
- 콘솔에서 API 키를 저장해도 실행 전 점검이 서버 환경 변수만 확인해 요청을 거부하던 문제를 고쳤습니다. 이제 에이전트가 실제로 사용할 환경을 기준으로 판정합니다.
- 화면 문구를 따옴표 없이 적어 스크립트가 YAML 문법 오류로 버려지던 문제를 줄였습니다. 한국어 화면 문구는 `검색어: 주간보고`처럼 콜론을 포함하는 경우가 많습니다. DSL 계약에 따옴표 규칙을 넣고, 재작성 요청에 정확한 오류 지점을 함께 전달하며, 이미 유효한 후보를 잃지 않도록 했습니다.

## 검증

- 전체 Go 테스트 494개와 `go vet ./...`.
- 로컬 데모 앱을 실제로 조작해 만든 화면 이미지와 6초 녹화로 요청을 접수하고, 세 가지 설정에서 끝까지 실행했습니다.
  - 내 API 키(GLM 5.3 Flash): 첨부에서 검색 흐름을 복원해 스크립트 생성, 실행 검증 통과.
  - 내 Claude Code: 첨부 판독 후 스크립트 생성, 대조 실험 수행.
  - 내 Codex: 영상 화면 8장을 순서대로 읽고 스크립트 생성, 실행 결과 통과.
- 브라우저에서 요청 폼에 직접 파일을 올려 접수부터 결과까지 확인했습니다.
- 금지한 브라우저 명령(`eval` 등)이 두 코딩 에이전트 모두에서 차단되는 것과, API 키가 증거 파일에 남지 않는 것을 확인했습니다.

자세한 사용 방법은 [관리 콘솔 안내](../docs/admin-console.md)를 참고하세요.
